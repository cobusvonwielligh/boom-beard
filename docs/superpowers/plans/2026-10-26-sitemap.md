# Sitemap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the canonical Boom Beard homepage through a standards-compliant sitemap and advertise it through robots.txt.

**Architecture:** Add two static files under `public/` so the existing static server exposes them without new runtime routes. Extend the server MIME table for XML and plain text, and cover the exact public contents and MIME mappings with a focused Node test.

**Tech Stack:** Node.js 20, `node:test`, static XML and plain text

---

### Task 1: Publish and verify sitemap discovery files

**Files:**
- Create: `test/sitemap.test.js`
- Create: `public/sitemap.xml`
- Create: `public/robots.txt`
- Modify: `server/index.js:33`

- [ ] **Step 1: Write the failing test**

Create `test/sitemap.test.js`:

```js
import { test } from 'node:test';
import assert from 'node:assert/strict';
import fs from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';

const ROOT = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..');
const read = rel => fs.readFileSync(path.join(ROOT, rel), 'utf8');

test('the public sitemap lists only the canonical homepage', () => {
  assert.equal(read('public/sitemap.xml'), `<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://boombeard.co.za/</loc>
  </url>
</urlset>
`);
});

test('robots.txt permits crawling and advertises the sitemap', () => {
  assert.equal(read('public/robots.txt'), `User-agent: *
Allow: /

Sitemap: https://boombeard.co.za/sitemap.xml
`);
});

test('the static server sends sitemap files with correct content types', () => {
  const server = read('server/index.js');
  assert.match(server, /'\\.xml':\\s*'application\\/xml; charset=utf-8'/);
  assert.match(server, /'\\.txt':\\s*'text\\/plain; charset=utf-8'/);
});
```

- [ ] **Step 2: Run the focused test and verify it fails**

Run: `node --test test/sitemap.test.js`

Expected: FAIL because `public/sitemap.xml` and `public/robots.txt` do not exist.

- [ ] **Step 3: Add the static sitemap**

Create `public/sitemap.xml`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://boombeard.co.za/</loc>
  </url>
</urlset>
```

- [ ] **Step 4: Add robots.txt**

Create `public/robots.txt`:

```text
User-agent: *
Allow: /

Sitemap: https://boombeard.co.za/sitemap.xml
```

- [ ] **Step 5: Add static MIME mappings**

Add these entries to `MIME` in `server/index.js`:

```js
  '.xml': 'application/xml; charset=utf-8',
  '.txt': 'text/plain; charset=utf-8',
```
